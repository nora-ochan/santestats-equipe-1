# Publier la version 0.2.0

**Pour : la personne qui a créé le dépôt de l'équipe** (partie 3)

## À faire

- [ ] Sur une branche `6-version-0-2-0` : dans `CHANGELOG.md`, renommer la section
      « Non publié » en `## [0.2.0] - <date du jour>` et recréer au-dessus une section
      « Non publié » vide.
- [ ] Dans `santestats/__init__.py`, passer `__version__` à `"0.2.0"`.
- [ ] Pull request, revue, fusion.
- [ ] Sur `main` à jour : créer l'étiquette annotée `v0.2.0` et la pousser.
- [ ] Sur GitHub, créer la *Release* `v0.2.0` à partir de cette étiquette,
      en reprenant les lignes du CHANGELOG.

## Critère de fin

La page *Releases* du dépôt affiche `v0.2.0`.
